# Dream Mini-Session Workflow

Use this when the user wants to start from a dream without turning it into a full weekly session.

Default shape:

- Keep the exchange around 3 to 7 minutes.
- Ask one or two clarification questions by default.
- Use the user's own associations before interpretation.
- Produce no summary, a one-sentence takeaway, a brief private note, a structured dream note, or a carry-forward note according to the user's request.
- Do not diagnose the user or impose fixed symbolic meanings.
- Save a note under `Dreams/` only if the user asks.
- Carry dream material into full-session continuity only if the user permits it, the theme repeats, or it is clearly relevant.
