# Psychology Reflection Reference Templates

These files are starter templates for a private working vault.

When creating a new vault:

1. Copy these reference files into the user's private vault.
2. Create `Sessions/`, `Dreams/`, `Reports/Monthly/`, and `Reports/Yearly/` if missing.
3. Tell the user that real session notes should stay local or private.
4. Tell the user that real dream notes should also stay local or private.
5. Begin with first-contact onboarding.

Prefer the user's live vault files over these references after the vault exists.
