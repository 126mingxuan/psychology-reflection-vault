# AI-Assisted Therapy Support

**Языки:** [English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md) | [한국어](./README.ko.md) | [Português](./README.pt-BR.md) | [Русский](./README.ru.md) | [العربية](./README.ar.md)

Local-first система AI-assisted терапевтической поддержки для непрерывных, структурированных психологических разговоров с памятью.

Она не заменяет профессиональную терапию. Цель проекта — поддерживать недорогую психологическую непрерывность: заметки сессий, формулировку случая, психологический профиль, выбор стратегии, расписание, месячные или годовые обзоры и отслеживаемую долгосрочную память.

> Важно: проект терапевтически ориентирован, но не является лицензированной психотерапией, медицинской диагностикой, психиатрической помощью или кризисной интервенцией. При непосредственной опасности обратитесь в экстренные службы, к квалифицированному специалисту или к человеку, которому доверяете.

## Ключевые Особенности

- **Local-first приватность**: реальные материалы остаются в вашем приватном рабочем пространстве или локальных файлах. В проекте нет сервера, скрытой базы данных или встроенной телеметрии.
- **Непрерывность, похожая на разговор с человеком**: каждая сессия может продолжать предыдущие темы, а не начинать с нуля.
- **Эффективное чтение долгосрочной памяти**: `09_Continuity_Index.md`, месячные и годовые отчеты помогают находить важное без перечитывания всего архива.
- **Терапевтически ориентированный workflow**: первичная оценка, структурированный разговор, активное завершение, обновление памяти и рекомендация для следующей сессии.
- **Адаптивная стратегия**: психодинамическое исследование, CBT-инструменты, семейные системы, mindfulness, экзистенциальная рефлексия, гуманистическая поддержка и границы безопасности.
- **Публичный шаблон, приватное рабочее пространство**: публичный репозиторий содержит переиспользуемую структуру; реальные личные материалы должны оставаться приватными.

## Quick Start

1. Нажмите **Use this template** или сделайте fork.
2. Создайте приватное рабочее пространство.
3. Откройте его через локальный файловый workflow, Markdown-редактор, приватный репозиторий или local-first AI workspace.
4. Заполните `01_Client_Profile.md` контекстом, который ассистент должен помнить.
5. Начните с этого prompt:

```text
Read AGENTS.md, the core continuity files, 09_Continuity_Index.md,
the latest psychological profile, the running case formulation,
and the latest relevant notes in Sessions/.
If the archive is large, read monthly/yearly summaries first.
Continue from previous material instead of starting from zero.
Start with one focused opening question.
```

## Use Cases

- непрерывная и недорогая психологическая поддержка;
- подготовка или сопровождение между профессиональными сессиями;
- local-first память для чувствительных разговоров;
- дизайн психологической непрерывности с AI.
