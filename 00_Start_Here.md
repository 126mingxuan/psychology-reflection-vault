# AI-Assisted Therapy Support

This is a local-first workspace template for ongoing AI-assisted therapy support conversations.

## How To Use

1. Copy, fork, or use this repository as a template.
2. If you will store real personal material, keep your working workspace private.
3. If this is the first session in a new private workspace, use `docs/ONBOARDING_QUESTIONNAIRE.md` to collect minimal setup context.
4. At the start of each session, ask your AI assistant to read `AGENTS.md`, the core files, the latest psychological profile, the running case formulation, and prior notes in `Sessions/`.
5. Use the local continuity files as the framework for the current conversation instead of relying on platform-level memory.
6. Ask the assistant to read context once at the start whenever possible, avoiding repeated file reads unless you request them or the session clearly requires them.
7. During the conversation, prioritize reflection over documentation and do not update durable memory after every message.
8. Use `docs/STRATEGY_ROUTING.md` to decide whether to continue, combine, or shift reflective strategy.
9. After each session, save one new note in `Sessions/`.
10. Continuously update `03_Running_Case_Formulation.md`.
11. Review and update the single current `05_Psychological_Profile.md` after every completed session. Stable evidence belongs in the profile; uncertain clues belong in provisional observations or items to confirm.
12. Record which reflective strategy was used and what strategy is recommended for the next session.
13. Create monthly summaries in `Reports/Monthly/` when enough material exists.
14. Create yearly summaries in `Reports/Yearly/` when enough long-term material exists.

## Boundaries

This workspace can support reflection, emotional organization, pattern tracking, therapy preparation, and practical next steps. It is therapy-oriented, but it is not licensed psychotherapy, psychiatric diagnosis, medical care, or emergency crisis support.

If there is immediate danger, self-harm risk, suicidal intent, or risk of harming someone else, contact local emergency services, qualified professionals, or a trusted person immediately.
