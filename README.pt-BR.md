# AI-Assisted Therapy Support

**Idiomas:** [English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md) | [한국어](./README.ko.md) | [Português](./README.pt-BR.md) | [Русский](./README.ru.md) | [العربية](./README.ar.md)

Um sistema local-first de apoio terapêutico assistido por IA para conversas psicológicas contínuas, estruturadas e com memória.

Ele não substitui terapia profissional. O objetivo é apoiar continuidade psicológica de baixo custo: notas de sessão, formulação de caso, perfil psicológico, roteamento de estratégia, acompanhamento, revisões mensais ou anuais e memória rastreável.

> Importante: este projeto tem orientação terapêutica, mas não é psicoterapia licenciada, diagnóstico médico, cuidado psiquiátrico ou intervenção de crise. Em caso de perigo imediato, risco de autolesão ou risco de ferir outra pessoa, procure serviços de emergência, profissionais qualificados ou uma pessoa de confiança.

## Destaques

- **Privacidade local-first**: o material real permanece no seu espaço privado ou em arquivos locais. Não há servidor do projeto, banco de dados oculto nem telemetria embutida.
- **Continuidade próxima de uma conversa humana**: cada sessão pode continuar a partir do material anterior em vez de começar do zero.
- **Leitura eficiente de memória de longo prazo**: `09_Continuity_Index.md`, relatórios mensais e relatórios anuais ajudam a encontrar o essencial sem reler todo o histórico.
- **Fluxo de apoio terapêutico**: avaliação inicial, conversa estruturada, fechamento ativo, atualização de memória e recomendação para a próxima sessão.
- **Estratégia adaptativa**: exploração psicodinâmica, ferramentas de TCC, sistemas familiares, mindfulness, reflexão existencial, apoio humanista e limites de segurança.
- **Template público, espaço privado**: o repositório público contém estrutura reutilizável; o material pessoal real deve permanecer privado.

## Quick Start

1. Clique em **Use this template** ou faça fork do repositório.
2. Crie seu espaço de trabalho privado.
3. Abra com qualquer fluxo local de arquivos, editor Markdown, repositório privado ou ambiente local-first de IA.
4. Preencha `01_Client_Profile.md` com o contexto que você quer que o assistente lembre.
5. Comece com este prompt:

```text
Read AGENTS.md, the core continuity files, 09_Continuity_Index.md,
the latest psychological profile, the running case formulation,
and the latest relevant notes in Sessions/.
If the archive is large, read monthly/yearly summaries first.
Continue from previous material instead of starting from zero.
Start with one focused opening question.
```

## Casos De Uso

- apoio psicológico contínuo e de baixo custo;
- preparação ou acompanhamento entre sessões profissionais;
- memória local-first para conversas sensíveis;
- design de continuidade psicológica com IA.
