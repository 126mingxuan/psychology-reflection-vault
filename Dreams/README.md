# Dreams

Private dream notes and dream mini-session summaries belong here in a real working vault.

Dream notes should be brief, optional, and treated as supplemental material. A single dream should not become a diagnosis, stable personality conclusion, or complete explanation of the user's psychology.

In this public template repository, real `Dreams/*.md` files should stay ignored. Use `docs/DREAM_MINI_SESSION.md` for the reusable workflow.
