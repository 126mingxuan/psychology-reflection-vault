# AI-Assisted Therapy Support

**Sprachen:** [English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md) | [한국어](./README.ko.md) | [Português](./README.pt-BR.md) | [Русский](./README.ru.md) | [العربية](./README.ar.md)

Ein local-first System für KI-gestützte therapeutische Unterstützung in kontinuierlichen, strukturierten psychologischen Gesprächen.

Es ersetzt keine professionelle Therapie. Ziel ist eine kostengünstige psychologische Kontinuität: Sitzungsnotizen, Fallformulierung, psychologisches Profil, Strategieauswahl, Terminlogik, monatliche oder jährliche Integration und nachvollziehbare Langzeiterinnerung.

> Wichtig: Dieses Projekt ist therapeutisch orientiert, aber keine lizenzierte Psychotherapie, medizinische Diagnose, psychiatrische Behandlung oder Krisenintervention. Bei akuter Gefahr kontaktiere lokale Notdienste, qualifizierte Fachpersonen oder eine vertraute Person.

## Kernpunkte

- **Local-first Datenschutz**: Reales Material bleibt in deinem privaten Arbeitsbereich oder in lokalen Dateien. Es gibt keinen Projektserver, keine versteckte Datenbank und keine eingebaute Telemetrie.
- **Gesprächskontinuität**: Jede Sitzung kann an frühere Themen anschließen, statt wieder bei null zu beginnen.
- **Effizientes Lesen langfristiger Erinnerung**: `09_Continuity_Index.md`, Monatsberichte und Jahresberichte helfen, wichtige Informationen schnell zu finden, ohne das gesamte Archiv zu lesen.
- **Therapeutisch orientierter Workflow**: Ersteinschätzung, strukturiertes Gespräch, aktiver Abschluss, Gedächtnisupdate und Empfehlung für die nächste Sitzung.
- **Adaptive Strategie**: psychodynamische Exploration, CBT-Werkzeuge, Familiensysteme, Achtsamkeit, existenzielle Reflexion, humanistische Unterstützung und Sicherheitsgrenzen.
- **Öffentliches Template, privater Arbeitsbereich**: Das öffentliche Repository enthält wiederverwendbare Struktur; echte persönliche Inhalte bleiben privat.

## Quick Start

1. Klicke auf **Use this template** oder forke das Repository.
2. Erstelle deinen privaten Arbeitsbereich.
3. Öffne ihn mit einem lokalen Dateiworlflow, Markdown-Editor, privaten Repository oder local-first KI-Arbeitsbereich.
4. Fülle `01_Client_Profile.md` mit dem Kontext aus, den der Assistent erinnern soll.
5. Starte mit diesem Prompt:

```text
Read AGENTS.md, the core continuity files, 09_Continuity_Index.md,
the latest psychological profile, the running case formulation,
and the latest relevant notes in Sessions/.
If the archive is large, read monthly/yearly summaries first.
Continue from previous material instead of starting from zero.
Start with one focused opening question.
```

## Anwendungsfälle

- kontinuierliche, kostengünstige psychologische Unterstützung;
- Vorbereitung oder Nachbereitung professioneller Therapie;
- local-first Gedächtnis für sensible Gespräche;
- Design psychologischer KI-Kontinuität.
