# AI-Assisted Therapy Support

**اللغات:** [English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md) | [한국어](./README.ko.md) | [Português](./README.pt-BR.md) | [Русский](./README.ru.md) | [العربية](./README.ar.md)

نظام محلي أولا لدعم علاجي بمساعدة الذكاء الاصطناعي، مخصص لمحادثات نفسية مستمرة ومنظمة ولها ذاكرة.

لا يستبدل العلاج المهني. هدفه دعم الاستمرارية النفسية بتكلفة أقل: ملاحظات الجلسات، صياغة الحالة، الملف النفسي، اختيار الاستراتيجية، المتابعة، المراجعات الشهرية أو السنوية، وذاكرة طويلة المدى قابلة للتتبع.

> تنبيه مهم: هذا المشروع ذو توجه علاجي، لكنه ليس علاجا نفسيا مرخصا أو تشخيصا طبيا أو رعاية نفسية أو تدخلا في الأزمات. إذا كنت في خطر مباشر أو معرضا لإيذاء نفسك أو غيرك، فاتصل بخدمات الطوارئ المحلية أو مختص مؤهل أو شخص موثوق.

## النقاط الأساسية

- **خصوصية محلية أولا**: تبقى المواد الحقيقية في مساحة عملك الخاصة أو في ملفات محلية. لا يوجد خادم للمشروع، ولا قاعدة بيانات مخفية، ولا تتبع مدمج.
- **استمرارية قريبة من الحوار البشري**: يمكن لكل جلسة أن تتابع المواد السابقة بدلا من البدء من الصفر.
- **قراءة فعالة للذاكرة الطويلة**: يساعد `09_Continuity_Index.md` والتقارير الشهرية والسنوية على العثور على المهم دون قراءة الأرشيف كله.
- **سير عمل علاجي التوجه**: تقييم أولي، محادثة منظمة، إغلاق نشط، تحديث للذاكرة، وتوصية للجلسة التالية.
- **استراتيجية تكيفية**: استكشاف ديناميكي نفسي، أدوات CBT، أنظمة العائلة، اليقظة، التأمل الوجودي، الدعم الإنساني، وحدود السلامة.
- **قالب عام ومساحة خاصة**: يحتوي المستودع العام على بنية قابلة لإعادة الاستخدام فقط، ويجب أن تبقى المواد الشخصية الحقيقية خاصة.

## Quick Start

1. اضغط **Use this template** أو قم بعمل fork للمستودع.
2. أنشئ مساحة عمل خاصة بك.
3. افتحها بأي سير عمل محلي للملفات، أو محرر Markdown، أو مستودع خاص، أو مساحة عمل AI محلية أولا.
4. املأ `01_Client_Profile.md` بالسياق الذي تريد من المساعد تذكره.
5. ابدأ بهذا الطلب:

```text
Read AGENTS.md, the core continuity files, 09_Continuity_Index.md,
the latest psychological profile, the running case formulation,
and the latest relevant notes in Sessions/.
If the archive is large, read monthly/yearly summaries first.
Continue from previous material instead of starting from zero.
Start with one focused opening question.
```

## حالات الاستخدام

- دعم نفسي مستمر ومنخفض التكلفة؛
- التحضير أو المتابعة بين الجلسات المهنية؛
- ذاكرة محلية أولا للمحادثات الحساسة؛
- تصميم الاستمرارية النفسية بمساعدة الذكاء الاصطناعي.
