# Getting Started

## What This Project Gives You

This repository gives you a local-first structure for recurring psychological reflection with AI support. It is built around Markdown files, not a hosted database.

Use it when you want:

- continuity between sessions;
- visible and editable memory;
- a clear public/private boundary;
- short, focused openings instead of long generic analysis;
- session notes that gradually build a useful profile.

## Basic Setup

1. Clone or download this repository.
2. Keep this public template separate from your private working vault.
3. Create a private folder for real reflection notes.
4. Copy the core Markdown files into the private folder.
5. Run the onboarding questions in `docs/ONBOARDING_QUESTIONNAIRE.md`.
6. Start the first session with a prompt from `docs/PROMPT_RECIPES.md`.

## Private Vault Checklist

A working vault should include:

- `AGENTS.md`
- `00_Start_Here.md`
- `01_Client_Profile.md`
- `02_Therapy_Framework.md`
- `03_Running_Case_Formulation.md`
- `04_Session_Template.md`
- `05_Psychological_Profile.md`
- `06_Scheduling_Policy.md`
- `07_Memory_Architecture.md`
- `09_Continuity_Index.md`
- `Sessions/`
- `Reports/Monthly/`
- `Reports/Yearly/`

## First Session

The first session should be an assessment-oriented beginning. Do not force deep interpretation immediately. Establish the user's current concerns, privacy boundaries, communication style, and desired rhythm.

Ask one question at a time.

## After Each Session

1. Save a dated note in `Sessions/`.
2. Update the running formulation if the working understanding changed.
3. Update the profile only when evidence is stable, repeated, or directly confirmed.
4. Update the continuity index.
5. Recommend the next check-in time.

## What Not To Do

- Do not publish real session notes.
- Do not treat the project as medical care.
- Do not update stable profile conclusions from one intense emotion.
- Do not ask many onboarding questions at once.
- Do not reread the whole archive every time once the vault becomes large.
