# Prompt Recipes

## Start A Session

```text
Use this folder as my psychology reflection vault.
Read AGENTS.md, 09_Continuity_Index.md, the core continuity files, and the latest session note.
Do not summarize everything.
Identify the most relevant thread and ask one focused opening question in my language.
```

## First Contact

```text
Use docs/ONBOARDING_QUESTIONNAIRE.md.
Ask one onboarding question at a time.
Do not diagnose me or ask for unnecessary private details.
After enough context is available, begin the first reflection session.
```

## Continue A Theme

```text
Continue from the latest session note and 09_Continuity_Index.md.
Focus on the unfinished theme rather than restarting from zero.
Use the most fitting strategy from docs/STRATEGY_ROUTING.md.
Ask one question first.
```

## Close A Session

```text
Please close today's session.
Summarize the core theme, name the main psychological clue, suggest one small observation task, recommend the next check-in time, and update the relevant vault files.
```

## Prepare A Monthly Report

```text
Review this month's session notes, the running formulation, psychological profile, and continuity index.
Create a concise monthly report under Reports/Monthly/.
Separate facts, emotions, interpretations, recurring patterns, and next-session priorities.
```
