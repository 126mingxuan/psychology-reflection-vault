# FAQ

## Is this therapy?

No. This is a structured, AI-assisted self-reflection and continuity system. It is not licensed psychotherapy, medical diagnosis, psychiatric care, or crisis intervention.

## Can I use it with a real therapist?

You can use it to organize thoughts, track patterns, and prepare questions. Do not treat it as a replacement for qualified professional care.

## Where should private notes live?

In a local folder or private repository. Do not publish real session notes or reports.

## Why use Markdown files?

Markdown is readable, editable, portable, and easy to review. The user can see what is being remembered.

## Why update memory only after a session?

Psychological material needs context. Updating durable memory after every message can overstate temporary emotion. Session-level updates are more careful.

## Why use a continuity index?

A long-running vault can become large. The continuity index helps future sessions find relevant material quickly without rereading everything.

## Can this work with different AI assistants?

Yes. The core method is model-agnostic. Agent-specific skills or prompts can adapt the same file structure.
