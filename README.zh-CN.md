# AI-Assisted Therapy Support

**语言：** [English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [Français](./README.fr.md) | [Deutsch](./README.de.md) | [한국어](./README.ko.md) | [Português](./README.pt-BR.md) | [Русский](./README.ru.md) | [العربية](./README.ar.md)

一个本地优先、AI 辅助的治疗支持系统，用于长期、连续、结构化的心理支持对话。

它的目标不是替代专业治疗，而是帮助用户以更低成本获得持续性的心理整理：会谈记录、持续个案理解、长期心理画像、策略路由、排期建议、月度/年度整合，以及可追溯的长期记忆。

> 重要提示：本项目具有治疗取向，但不是持证心理治疗、医学诊断、精神科服务或危机干预。如果你处于即时危险、自伤/自杀风险，或可能伤害他人的状态，请立即联系当地紧急服务、专业人员或可信任的人。

## 核心特点

- **本地优先隐私结构**：真实材料保存在你的私人工作区或本地文件中，项目本身没有服务器、隐藏数据库或内置遥测。
- **接近真人对话的连续性**：每次会谈都能继承之前的重点，而不是从零开始。
- **高效长期记忆读取**：通过 `09_Continuity_Index.md`、月报和年报快速定位关键材料，避免半年或一年后每次读取全部历史。
- **治疗取向的工作流**：支持初始评估、会谈推进、主动收束、长期记忆更新和下一次策略建议。
- **自适应策略路由**：根据用户当下材料，在心理动力学、CBT 工具、家庭系统、正念、存在主义、人本支持和安全边界之间调整。
- **公开模板，私人工作区**：公开仓库只保存可复用结构和示例，真实个人内容应保存在私人位置。

## 快速开始

1. 点击 **Use this template** 或 fork 本仓库。
2. 创建你自己的私人工作区。如果会保存真实个人内容，请保持私密。
3. 用任意本地文件工作流、Markdown 编辑器、私有仓库或本地优先 AI 工作区打开。
4. 在 `01_Client_Profile.md` 填入你希望 AI 记住的背景。
5. 用这个提示开始：

```text
Read AGENTS.md, the core continuity files, 09_Continuity_Index.md,
the latest psychological profile, the running case formulation,
and the latest relevant notes in Sessions/.
If the archive is large, read monthly/yearly summaries first.
Continue from previous material instead of starting from zero.
Start with one focused opening question.
```

## 适合谁

- 想要低成本、长期连续心理支持的人；
- 想在专业治疗前后整理主题、情绪和问题的人；
- 想保留本地隐私控制、但又希望 AI 有长期记忆的人；
- 对 AI 长期记忆、心理画像和会谈连续性设计感兴趣的建设者。
