# Fictional Full Session Lifecycle Example

This is a fictional example. It does not describe a real person.

## 1. First-Contact Onboarding Excerpt

```text
Assistant:
Before we start the first reflection session, I can ask a brief setup questionnaire so the vault can remember your preferences and choose a better reflective strategy. You may skip any question. Please share only what you want stored in this private vault.

User:
I want to understand why I become tense whenever I need to ask for help. I prefer a balanced style: emotional reflection first, then practical steps. Please do not push too quickly into family history unless I bring it up.
```

## 2. Profile Entry After Onboarding

```md
# Client Profile Template

## Communication Preferences

- Preferred response style: balanced; emotional reflection before practical steps.
- Preferred session pace: start gently, then focus.
- Boundary: do not push into family history unless the user introduces it.

## User-Written Notes

- The user wants to understand tension around asking for help.
```

## 3. Standard Session Invocation

```text
Read AGENTS.md, the core vault files, the latest psychological profile, the running case formulation, and prior session notes in Sessions/.
Use this vault as the framework for this conversation.
Continue from previous material instead of starting from zero.
Read context once at the start unless I explicitly ask you to reread.
Use adaptive strategy routing to choose the reflective lens.
Start with one focused opening question.
```

## 4. Abbreviated Session Exchange

```text
Assistant:
Last time, the starting theme was tension around asking for help. When this appeared most recently, what did you need from the other person, and what felt risky about asking?

User:
I needed a classmate to explain part of an assignment, but I felt embarrassed. I kept thinking they would see me as careless.

Assistant:
It sounds like the practical request was small, but the emotional meaning became much larger: asking for help started to feel like being exposed as inadequate. When that thought appeared, did you withdraw, over-prepare, or try to solve everything alone?

User:
I over-prepared and then did not ask. I spent three extra hours trying to avoid looking stupid.
```

## 5. Session Note Excerpt

```md
# Session Note Template

Date: 2026-01-01

## Reflective Strategy Used

- Primary lens: psychodynamic reflection.
- Supporting lenses: cognitive-behavioral tools.
- Why this strategy fit this session: the user described a repeated self-worth threat around asking for help, with a concrete avoidance pattern.
- Should the next session continue or shift strategy: continue psychodynamic exploration, add a small behavioral experiment if the user feels ready.

## Explicit Facts Mentioned By The User

- The user avoided asking a classmate for help with an assignment.
- The user spent three extra hours trying to solve the issue alone.

## Emotions And Body State

- Embarrassment.
- Tension around being seen as careless or inadequate.

## Psychological Understanding From This Session

- Tentative hypothesis: asking for help may activate a self-worth threat, where needing support becomes linked to being seen as inadequate.
- Needs further validation: whether this pattern appears in work, friendships, family, or only academic contexts.

## Small Practice Or Observation Task

- Before the next session, notice one moment when asking for help feels risky. Record the request, the feared judgment, and what the user actually does.

## Next Scheduling Recommendation

- Suggested next trigger time: one week.
- Scheduling rationale: the theme is active but not described as an immediate safety issue.
- Recommended strategy for the next session: continue psychodynamic reflection with one CBT-style behavioral experiment if appropriate.
```
