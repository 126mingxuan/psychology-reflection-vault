# Fictional Full Session Lifecycle Example

This example is fictional and public-safe.

## 1. Startup

The assistant reads:

- `AGENTS.md`
- `09_Continuity_Index.md`
- `03_Running_Case_Formulation.md`
- `05_Psychological_Profile.md`
- latest `Sessions/*.md`

## 2. Opening Question

```text
Last time, avoidance seemed connected to fear of being evaluated. What happened this week when you approached the task, and what feeling appeared first?
```

## 3. Exploration

The user describes opening the file, feeling chest tightness, and switching to unrelated tasks.

The assistant reflects:

```text
It sounds as if the body reacts before the thought becomes fully clear. Let us slow down around the moment before you switch tasks: what do you imagine would happen if you continued?
```

## 4. Strategy

Primary strategy: CBT-style behavioral step.

Secondary strategy: psychodynamic inquiry into shame and evaluation.

## 5. Closing

The assistant summarizes the pattern, suggests one small exposure step, and recommends the next check-in time.

## 6. Memory Updates

The assistant writes:

- a dated session note;
- a formulation update if the fear-of-evaluation pattern repeated;
- a profile update only if the user confirms this is a stable pattern;
- a continuity index update pointing to the next opening question.
