# 2026-01-09 Fictional Session Note

This example is fictional. Do not copy real personal material into public examples.

## Session Focus

The user described feeling stuck after postponing an important work task for several days.

## Fact Layer

- The task has a deadline next week.
- The user opened the document several times but stopped after a few minutes.
- The user said the task feels "too visible" and hard to begin.

## Emotion Layer

- Anxiety increased when the user imagined others reading the result.
- Shame appeared after each period of avoidance.
- Relief appeared when the task was broken into a small first step.

## Interpretation Layer

- Provisional: avoidance may be less about laziness and more about fear of being judged.
- Provisional: the user may need a smaller exposure step before attempting the whole task.

## Strategy Used

Primary strategy: CBT-style tools.

Secondary strategy: psychodynamic reflection around visibility and shame.

## Closing Summary

The session clarified that the main difficulty is not simply time management. The task activates anxiety about being evaluated, which then leads to avoidance and shame. The next step is to write a rough outline that no one else will see.

## Practice

Spend 15 minutes creating a private outline. Stop after 15 minutes even if it feels unfinished.
